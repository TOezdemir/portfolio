# 🌐 Portfolio – tolgay-oezdemir.de

Persönliche Portfolio-Website von Tolgay Özdemir – gebaut mit Vanilla HTML, CSS und JavaScript, deployed via Vercel.

🔗 **[Live → tolgay-oezdemir.de](https://tolgay-oezdemir.de)**

---

## ✨ Features

- **Zweisprachig (DE / EN)** – vollständiger Sprachumschalter via JavaScript i18n ohne externe Bibliothek
- **Responsive Layout** – CSS Grid-basiertes Design, optimiert für alle Bildschirmgrößen
- **Consulting Cases** – ausführliche Case Studies zu eProcurement-Projekten (van Laack & Partners, Parasus)
- **Barrierefreiheit** – Skip-Link, semantisches HTML, ARIA-Labels
- **Kein Framework** – bewusst ohne React oder Build-Tool, reines Vanilla Web

---

## 🛠️ Tech Stack

| Bereich | Technologie |
|---|---|
| Markup | HTML5 (semantisch) |
| Styling | CSS3 (Custom Properties, Grid, Flexbox) |
| Interaktion | Vanilla JavaScript (ES6+) |
| Deployment | Vercel |

---

## 📁 Projektstruktur

```
/
├── index.html          # Hauptseite
├── vanlaack.html       # Case Study: van Laack & Partners
├── parasus.html        # Case Study: Parasus
├── styles.css          # Globales Stylesheet
└── main.js             # i18n, Navigation, Jahr-Update
```

---

## 🚀 Lokal starten

Kein Build-Schritt nötig – einfach öffnen:

```bash
git clone https://github.com/TOezdemir/portfolio.git
cd portfolio
# index.html direkt im Browser öffnen
# oder mit einem lokalen Server:
npx serve .
```
